Left third — grounding & ideation. planner → ensure_locations → ground_entities → ground_rag → gen_concept → evaluate. Unchanged, live, and verified against real Gemini calls. The evaluate → gen_concept edge is the self-correcting retry loop: failed critique issues get folded into the next spark, up to MAX_ATTEMPTS = 3.
The credit gate. structure_prompt → score_prompts extracts each AI shot's prompt and runs it through a two-layer judge (deterministic structural check, then a strict LLM rubric). Every score is logged before any spend. All prompts must pass, or the whole run holds — no partial renders.
The posting line — deliberately stubbed. generate_render only calls real Veo when ZEROPAGE_RENDER=1; otherwise every clip returns ok=False by design. publish has no wired posting API yet — even an auto-autonomy channel currently parks with an explicit reason.
The sink. Five different failure points converge on one hold node, which inspects state to write a human-readable reason to hold_queue — the dead-man log every run writes to, pass or fail.
