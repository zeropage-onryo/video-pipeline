# Step 3 — Cast & places

Goal: every face and recurring place in the scene is an Element with real photos.

- Name who and where the scene needs. Check whether each already exists as an @Element (ask; do not invent one).
- A face is ALWAYS an Element built from real photos of that person — never a web image, never a generated stranger.
- A place can be an Element or can come from the reference hunt next.
- New Elements are made on the Elements page with the New element button; point there.

Done when: each face in the scene is a named Element. Nudge toward References.
