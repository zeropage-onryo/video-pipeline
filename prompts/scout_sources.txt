# Every URL below was fetched and parsed before being committed
# (2026-08-31). Do the same when adding one: a feed that 403s is not a

# rate-limits datacenter traffic hard. scout._parse_reddit and
# _reddit_image still exist and still work, because a run from a home IP
# (or with an OAuth token in front of it) does get through, and Reddit
# preview images are good bin material. Uncomment a line below if yours
# does; expect it to contribute nothing if it doesn't.
#
# Blank lines and # comments are ignored. Nothing here is required: an
# empty file means the feeds lane contributes nothing and the other
# three lanes still run.
